# OAFBLOG.COM — Vintage NBA Daily

Open `index.html` in a browser.

## What it does
- Vintage sports/trading-card visual style
- Daily player feature changes automatically with the calendar
- Archive grid
- Responsive mobile layout
- Photo URLs are external and should be replaced with images you have permission to use/licensed images

## Important content note
This starter site does not classify NBA players by race. Race is a sensitive personal attribute, and the site instead uses an objective historical scope: NBA frontcourt players from the 1970–1999 era. You can expand the player dataset in `players.js`.

## Expanding the archive
Add objects to the `players` array with:
name, years, pos, team, summary, image
